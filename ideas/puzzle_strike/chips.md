# Puzzle Strike — the chips, transcribed

Read off the photographs in this folder (`most cards scan.jpg`,
`more cards.jpg`, `more character chips.jpg`, `even more character chips.jpg`,
`even more cards.webp`, `4 more.webp`, `argarga and fox.webp`,
`promo chips.webp`, and the six `Screenshot_*.png`), which are the owner's own
**third edition** set. Where a photo disagrees with a secondary source the photo
wins; where a chip is obscured or absent it is listed under *Missing* rather
than guessed at.

`rules.md` is the rulebook; this file is the components.

## The symbol vocabulary

Every chip says what it gives in icons rather than words, and the same four
icons cover almost everything:

| Icon | Means |
|---|---|
| black arrow ➤ | +1 action this turn |
| coloured arrow (yellow / red / blue / purple / brown) | +1 action, restricted to a chip whose banner is that colour |
| piggy bank | +1 buy this turn |
| dark filled circle | +1 chip drawn |
| green `$N` | +N gem power (money) this turn |
| green square with a number | a gem of that value |
| black puzzle piece | a Puzzle chip |
| coloured dot | a chip with that banner colour |

`One of Each` is the proof: cost 5, one of each of the four — an arrow, a
buy, `$1`, and a chip. A banner's colour is also its *type* — red is an
attack, blue is a reaction, purple is a crash-family chip, brown/tan is plain.

## The bank, always present

Every one of these is in the bank in every game, at the box quantity less
whatever the starting decks took (rules.md §3).

| Chip | Cost | Text |
|---|---|---|
| 1-gem | 1 | value 1 |
| 2-gem | 3 | value 2 |
| 3-gem | 5 | value 3 |
| 4-gem | 7 | value 4 |
| Combine (purple) | 4 | Combine two gems in your gem pile into one, if the total is 4 or less. −$1. +1 action |
| Crash Gem (purple) | 5 | Break one gem in your gem pile and send that many 1-gems to a chosen opponent. +$1 |
| Double Crash Gem (purple) | 9 | As Crash Gem, up to two gems. +$2 |
| Wound | 0 | "This chip does nothing." |

**Third edition costs confirmed against second edition.**
`Screenshot_20260823_101124.png` photographs both editions side by side: One of
Each went 6 → **5**, One-Two Punch 5 → **4**, Iron Defense 5 → **4**. Every cost
in this file is the third-edition one — the lower of each pair, and the one on
the owner's chips.

## Character chips

Ten base characters (rules.md §8): **Grave, Jaina, Midori, Setsuki, Rook,
DeGrey, Valerie, Geiger, Lum, Argagarg**. Each brings exactly three named
chips, and every starting deck is otherwise identical: 3 character chips,
1 Crash Gem, 6 1-gems.
