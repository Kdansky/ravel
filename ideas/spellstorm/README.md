# Spellstorm — source notes

Everything extracted from the Spellstorm print files, for building the game in the ravel engine.

**Spellstorm** — Keith Burgun, 2024. Tactical deckbuilding card game, 1–4 players, eight asymmetrical wizards.
Win by collecting 8 Storm Shards or by reducing every opponent to 0 health.

## Tools

`tools/extract_card.py <in.pdf> <out.jpg> [dpi] [maxpx]` — pull the artwork out of one print-template PDF.

Each print file is one card sitting on a spec sheet, with **every previously exported card left behind as a
stacked layer**, so the file grows through the export order and a naive `pdfimages` dump returns the wrong
card (and in inverted CMYK). The script instead parses the image placement rectangles out of the content
stream, picks the largest one, renders the page with `pdftoppm`, and crops to it.

`tools/extract_all.py <subdir> <outdir>` — batch a whole folder, slugifying names and dropping duplicates by
hash. Many source files are `foo - Copy (3).pdf`, which are print quantities of the same card, not variants;
the counts in the card files come from how many copies exist.

`tools/montage.sh <imagedir> <outdir>` — tile a folder into 2×2 sheets for reading.

`tools/spellstorm_art.py` — copy the card faces into `game/games/assets/` as
`ss_*.jpg` for the playable version. The extraction here keeps each card at its
full **print bleed** (825×1125 = 69.85 × 95.25 mm, where the card is 63 × 88 mm),
which is invisible on art that runs to the edge and looks like a mistake on the
eighteen discard-effect cards, whose printed frame is white and whose bleed is
therefore white too. The script crops everything to the trim line, so a white
border ends up the width it is on the physical card.

## Raw text

`raw/rulebook-layout.txt` and `raw/rulebook-flow.txt` — `pdftotext` output of the rulebook, the only PDF in
the set with a real text layer. Every card is a flattened image, so all card text here was transcribed by
reading the art.

## The playable version

`game/games/spellstorm.json`, generated by `tools/make_spellstorm.py` and
reachable from the menu. Two players, all eight wizards, 130 card templates.
`ideas/spellstorm/09-engine-gaps.md` lists everywhere it departs from the
printed rules and `10-closing-the-gaps.md` proposes a fix for each; the card art
is in `game/games/assets/` as `ss_*.jpg`.

## Known gaps in these notes

- Two token types on punchboard 2 are unlabelled — see the end of `08-boards.md`.
- The Oren potion cards print "POISON" where the rulebook says "CURSE"; treated as the same thing.
- The Spellstorm Board says "Gem Shards" once where everything else says "Storm Shards".
