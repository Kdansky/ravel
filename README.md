This is a board-game engine based on LOVE2D, running either directly via the engine, or also in a web page. Can load any board game declaring its rules via json.

Features:
* Bots
* Networked play against other people
* Load art dynamically
* No need to distribute your game, just open the web page and send them an invite
* Save/Load/Undo

Currently included: Chess, Splendor, Lost Cities, Puzzle Strike, Codex, Spellstorm
