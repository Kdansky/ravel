# Card art prompt table

One row per card key. Generate at **512×640 (portrait)**, then set the card's
`"asset"` field — the GUI hot-reloads, so results show up in the running game.

**Shared style clause (append to every prompt):**
> flat gouache illustration, muted palette, soft directional light, single
> clear subject, no text, no borders, painterly, subdued fantasy
